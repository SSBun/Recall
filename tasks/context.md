# 工作区上下文

## 系统边界

- RAG 命令按规范化 store 路径自动连接或启动一个本地 Unix socket daemon；每个 store 单独进程并串行复用一个 `RecallApp`/Chroma/Qwen3，完成请求后空闲 30 分钟退出，运行目录为 `~/.local/state/recall/daemons/`（目录/socket `0700`/`0600`）；请求会转发当前 CLI 环境以保留模型、并发和 provider 环境变量语义；`provider` 与 `config` 命令保持前台直连且不启动 daemon——不得让多个 store 共用进程或把凭据写入 daemon 协议日志——权威来源：[src/recall/daemon.py](../src/recall/daemon.py)、[src/recall/cli.py](../src/recall/cli.py) 与用户确认，进程、transport、配置或 store 边界变化时复核。
- 嵌入模型固定为 `Qwen/Qwen3-Embedding-0.6B`：文档调用 `encode_document`，查询调用带 instruction 的 `encode_query`，均归一化为 1024 维向量；Chroma collection 必须记录并校验模型名与维度，任何模型切换都要完整重建 store，不能混用旧向量；加载时先使用本地缓存，缺失才联网下载，并在导入前关闭 Hugging Face/Transformers 提示与进度条——权威来源：Qwen 官方模型卡、[src/recall/embedding.py](../src/recall/embedding.py)、[src/recall/store.py](../src/recall/store.py) 与中英跨语言真实检索 smoke，模型或输出边界变更时复核。
- 机器 API 使用版本化 `{version: 1, ok, data|error}` envelope：stdout 只承载结果，stderr 承载诊断；参数/配置错误退出 `2`，运行或部分失败退出 `1`；批量失败需保留逐文档错误；所有层级的 argparse help 与附带 help 的 usage error 必须使用英文；默认人类输出必须表达任务语义而非转储内部 JSON，例如 `provider list` 按支持的认证供应商显示已连接/未连接，只有 `--json` 返回 provider ID/type——模型集成测试不得依赖真实账号或网络，迁移到内嵌 SDK 后使用 Pi 的 `fauxProvider`，并以临时 Chroma store 覆盖本地集成边界——权威来源：用户确认、[src/recall/cli.py](../src/recall/cli.py) 与 Pi SDK 测试能力，机器协议、人类输出、模型运行时或验证边界调整时复核。
- 索引并发默认值为 `4`，配置优先级固定为 `recall index --concurrency` > `RECALL_INDEX_CONCURRENCY` > `~/.config/recall/config.toml` 的 `[index].concurrency` > 默认值；有效值必须是正整数，机器输出需记录实际值——权威来源：用户确认，配置载体或优先级调整时复核。
- `search` 与 `ask` 共用默认检索数量：显式 `--limit` > `~/.config/recall/config.toml` 的 `[search].limit` > `5`；`recall config list/set` 可脚本化管理 `search.limit`、`models.tag`、`models.ask`，纯 `recall config` 启动显示当前值并编辑三项设置的单选菜单向导，其中模型选择只列出 Recall 凭据或当前环境已配置 provider 的全部可用 `provider/model`，脚本化 set 仍允许预设任意合法引用；配置采用 `0600` 原子定点更新并保留其他 TOML 内容——权威来源：用户确认、[src/recall/config.py](../src/recall/config.py)、[src/recall/config_prompt.py](../src/recall/config_prompt.py)、[src/recall/pi_client.py](../src/recall/pi_client.py)、[runtime/model-bridge.ts](../runtime/model-bridge.ts) 与 [src/recall/cli.py](../src/recall/cli.py)，配置命令、模型目录、默认检索或 shell 边界变化时复核。
- 批量索引必须提供单一 `index.concurrency` 资源旋钮，限制同一时间进入预处理流水线的文档数；Pi 标注继续按 token 预算批处理，Qwen3 继续批量编码，Chroma 继续逐文档提交——不得把该值解释为并行 Pi 进程数——权威来源：用户确认，并发语义或流水线边界调整时复核。
- 批量 `recall index` 采用逐文档提交：单个文档失败不得改变其旧索引或阻止其余文档处理，命令最终汇总成功/失败项并在任一失败时返回非零退出码——批处理优化不得削弱文档级隔离——权威来源：用户确认，批处理或事务语义调整时复核。
- `recall index --no-tag` 显式跳过 Pi：新文档以空标注入库，已有文档重新索引时保留原 `category`、`tags`、`summary`；该参数不得与 `--tag-model` 同时使用——禁用自动标注不能隐式清除已有 metadata——权威来源：用户确认，标注覆盖语义调整时复核。
- `recall ask` 默认只能依据检索片段回答并附来源，证据不足时明确说明；只有显式 `--allow-general-knowledge` 才允许 Pi 用模型常识补充，且输出必须区分知识库证据与模型补充——权威来源：用户确认，回答可信边界或引用语义调整时复核。
- 首次索引为文档生成稳定 UUID `document_id`，`source_path` 仅作可变定位信息，`content_hash` 用于变更与简单重命名检测：同路径沿用 ID；新路径与唯一缺失来源内容相同则沿用 ID；复制或歧义场景生成新 ID；路径和内容同时变化时由 `recall index --document-id <id>` 显式关联——不得用内容哈希或路径直接充当永久身份——权威来源：用户确认，文档身份或迁移语义调整时复核。
- 全局 CLI 默认将完整 Chroma 数据目录保存到 `~/.local/share/recall/db/`，并允许 `--store <path>` 覆盖；SQLite 与 HNSW 索引文件共同构成可备份/迁移单元——不得只复制 `chroma.sqlite3`——权威来源：用户确认，存储布局或迁移策略调整时复核。
- CLI 使用 `recall index <path...>` 统一新增与更新并保持幂等 upsert，不提供语义重复的独立 `add` / `update` 命令；文档身份不得仅由路径派生，因为路径只是可变化的来源定位信息——外部集成应使用稳定 `document_id`——权威来源：用户确认，文档身份或命令面调整时复核。
- 文档写入默认必须通过 Pi 生成并校验文档级 `category`、`tags`、`summary` 后再持久化；Pi 失败时终止写入，只有显式 `--no-tag` 才允许无标签入库——索引更新必须避免留下半写入状态——权威来源：用户确认，标注策略或写入事务边界调整时复核。
- Recall 的 Python 核心通过包内 `model_bridge.mjs` 的版本化 JSON stdin/stdout 协议调用 `@earendil-works/pi-ai`，bridge 构建产物随 Python wheel 分发；运行时只要求 Node.js，不调用外部 `pi` 可执行文件，也不读取 Pi 全局配置；独立 esbuild bundle 必须调用 Pi SDK 的 `registerBunOAuthFlows()` 静态包含 OAuth loader，避免 wheel 运行时解析不存在的相对模块——bridge 源码变化必须先重新构建，并让生成物和 wheel 执行所有受影响的懒加载操作——权威来源：用户实测、[runtime/model-bridge.ts](../runtime/model-bridge.ts)、[tests/test_pi_client.py](../tests/test_pi_client.py) 与 [pyproject.toml](../pyproject.toml)，CLI 运行时、SDK 或模型集成边界调整时复核。
- 模型选择优先级是命令参数 > 对应用途的 `RECALL_TAG_MODEL` / `RECALL_ASK_MODEL` > `~/.config/recall/config.toml` 的 `[models]` > `openai/gpt-4o-mini`，引用必须是 `provider/model`；供应商认证使用标准环境变量或 Recall 专属 `~/.config/recall/auth.json`，其中 `provider login openai-codex` 支持 ChatGPT Plus/Pro OAuth，省略 provider 时只通过 cmd2 显示认证供应商选择向导；Recall 不提供通用交互式 shell，纯 config 仅提供菜单式 setup 向导；登录和刷新结果以跨进程锁、原子替换及目录/文件 `0700`/`0600` 权限持久化，不读取 Pi 全局认证——权威来源：[src/recall/config.py](../src/recall/config.py)、[src/recall/provider_prompt.py](../src/recall/provider_prompt.py)、[runtime/model-bridge.ts](../runtime/model-bridge.ts)、[runtime/credential-store.ts](../runtime/credential-store.ts) 与用户确认，模型配置或认证能力调整时复核。
- Chroma 数据库与个人原始文档属于本地运行时数据，不应作为源码提交——仓库忽略规则必须覆盖 `db/` 与 `data/` 内容——权威来源：[RAG技术选型文档.md](../RAG技术选型文档.md) 与 [`.gitignore`](../.gitignore)，存储策略调整时复核。
